# Movie Tracker

A small, self-contained movie library. Open `index.html` in a modern browser to use it; there is no install step or account required.

The starting library contains the 644 rows from `Movies_list - Sheet1.csv`. Blank statuses appear as **Unsorted**. The app supports Completed, Plan to watch, Watching, Dropped, and Unsorted, plus optional ratings from 0 to 10.

## Keeping your list

Changes are saved in the browser on this device. Use **Export CSV** to keep a portable backup; **Import CSV** replaces the current browser list after confirmation. The CSV uses `Movie`, `Status`, and `Rating` columns, so it remains compatible with the original sheet.
